# 黄果搜索、分类与线路恢复

## 搜索范围

黄果剧库聚合旧黄果、黄果 AI 和黄果视频；联网搜索仍只请求黄果 AI。输入时匹配的已保存资料不能在联网结果为空后消失。

提交后分别展示“黄果 AI 线上结果”和“本地已找到”。线上顺序、分页、缓存、重试继续由原搜索会话维护；本地只匹配当前关键词和当前站源的已保存资料，并排除已经在线上展示的作品。同名但不同 ID 的作品不合并身份或进度。加载更多后再次去重；改词、切源及取消继续隔离旧请求。离线仍使用原本的本地搜索。

手机保留统一卡片和明暗主题，窄屏、大字体与键盘使用同一可滚动页面。电视焦点能经过线上卡片、分页/重试按钮和本地卡片；延迟创建的行继续由既有网格负责。

## 分类与资料缓存

发现、搜索和详情的题材入口开放黄果 AI 已有的四个真实频道 ID：`ai-duanju`、`ai-manju`、`ai-huanlian`、`ai-mogai`。频道名称沿用现有站源映射，按该频道的实际分页读取；普通题材标签仍只匹配已保存资料，不把标签词冒充线上分类或剧名搜索。

原剧库继续使用三个子源聚合、原有筛选和各自游标；独立频道读取不改变它们。频道资料沿用现有元数据缓存，不新增分区或保存格式；旧版本仅有资料缓存时，离线剧库仍可查看，未缓存的频道不混入其他分类资料。黄果聚合剧库继续按需加载，不新增自动预取。

题材页面取得的资料写入已有资料缓存，供后续本地搜索和离线使用，不改变当前来源、剧库分类或搜索输入。离页取消固定来源、频道、页码及请求 ID 的读取，迟到结果不安装到页面或资料缓存。相同的题材缓存和前台取消修复也适用于其他已有分类源。

## 有界恢复

自动模式下，新 API 遇到临时连接/服务错误或可恢复的数据格式异常，可在官网已发布的线路中尝试另一个来源。每次读取最多两次 API 尝试，共享调用方取消及最长 16 秒的 API 预算；只有通过对应分页、作品或分集校验的响应才在本次运行内记住线路。刷新官网线路列表保留仍在列表中的有效偏好。

API 不支持时继续立即使用原有旧路径，避免冷启动分类读取反复探测。账号/验证拒绝、限流、取消、错误作品或分集不启动额外恢复；合法的空搜索也不被当作线路故障。媒体地址和 Referer 使用实际响应线路，继续走原有 HLS、代理、下载和投屏流程。

手动固定线路及配置文件明确指定的内容入口只使用该来源，包括旧路径回退。用户切换线路后，旧请求即使迟到，也不能覆盖新选择或后来恢复的自动模式。
