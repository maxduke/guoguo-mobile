# HGhub 黄果适配与线路选择

参考版本：[Minireel/HGhub `8665ffcaa553bc6eb1b52629fd91b35cc6e02678`](https://github.com/Minireel/HGhub/tree/8665ffcaa553bc6eb1b52629fd91b35cc6e02678)。只吸收本轮已确认有价值的黄果接口和线路管理做法。

## 实现范围

- 黄果 AI 子站接入匿名 edge JSON 读取：分类、搜索、详情、分集、播放和榜单。旧黄果 CloudFront、黄果视频及其他站源保持各自入口。
- 延续 `huangguoai:<作品 ID>`，分集采用原有 `1`、`ep-2` 等键。只使用所请求作品与分集的响应；保留真实集号和缺集，不以队列位置补造分集。JSON 大整数使用 `json.Number`，详情没有分类时不以域名覆盖已有分类。
- 不支持新接口时，继续使用既有网页或分类 JSON 路径；404/405/501 和缺少信封的响应短期记住五分钟，用户主动检测可重新验证。401/403/429、业务拒绝、已取消及错误作品/分集响应不触发额外的旧路径请求。
- API 只包装匿名 GET，不发送账号 Cookie 或 Token，不跟随重定向；沿用原有请求限流、调用期限和公网 DNS 校验。只有内部标记的新入口 POST 可以通过既有公网固定地址传输，每次连接尝试重新取得请求体。
- 解析后继续走已有 HLS、媒体代理、下载、投屏及下一集准备路径。

## 线路入口

设置 → 黄果线路。打开页面或点击刷新时读取官网当前入口发布的线路，不批量测速。用户可以逐条检测、选择线路并记住，或恢复自动选择；仅影响黄果 AI 子站的新请求。

检测通过实际目录 API 的响应结构和分页验证判定。首页或 HTTP 200 本身不代表接口可用；结果明确标记尚未验证媒体。检测不会替用户切换线路，迟到的请求不能覆盖新的手动选择。设置通过临时文件原子替换保存，保存失败保留原选择，不修改作品、收藏、历史、下载或正在使用的播放资源。

线路仅来自官方发现结果或本机上次保存的选择；不提供任意地址输入。HTTPS、标准端口和公网 DNS 限制继续生效。复制诊断仅包含域名、HTTP 状态、耗时和固定失败类型，不带资源链接、凭据或异常原文。

## 联网样本与验证

初步只读采样确认：官方 `.com` 入口在本机出现 TLS 失败，`.ai` 首页返回 HTTP 200，但 edge API 返回 404；由官网当前发布的内容镜像则取得目录、搜索、详情、播放信息和热播榜 JSON。因而本轮保留现有官网线路发现，并检查 API 数据，不直接把 HGhub 的默认域名或首页测速作为可用性依据。

最终本地验证：

- Go 全量 696 个测试/子测试通过，零失败；8 项既有显式启用型的站源联网巡检未开启。FFmpeg 合成解密、断流恢复及旧源密钥回归实际执行。
- Flutter 全量 1017 项通过；该轮因未指定输出文件跳过的 3 项主机性能测量随后使用 `GUOGUO_PERF_OUTPUT` 单独全部通过。线路页和设置入口的 16 项局部回归也通过。
- 黄果和共享图片传输的相关 `go test -race`、`go vet ./...`、`flutter analyze`、Go/Dart 格式检查及 `git diff --check` 通过。主机使用 Go 1.26.6、Flutter 3.47.4，未把本地结果表述为 CI 的 Go 1.27.1 结果。
- Android 线路选择进入已有控制队列，避免等待挂起的联网工作。JDK 17 下现有调度回归 4 项通过，实际插件源码使用 Android 36 SDK、Flutter embedding 和 gomobile 绑定完成 Kotlin 编译；没有据此宣称整包构建或真机验收。
- 使用应用的实际 Go 核心和媒体代理完成独立联网抽查：发现 3 条官网线路，AI 分类目录返回 96 项，详情/选集返回 21 集，搜索返回 24 项，热播榜返回 20 项；一张加密封面解码为 174,813 字节 JPEG，一个媒体首段取得 HTTP 206 / 1024 字节。
- 同一作品另做旧网页与新 API 对照，21 个分集的 ID 和真实集号逐一一致。

主机媒体首段抽查没有完成该集整段解码，也不代替 iPhone / iPad、Android / TV 的实际画面、切集、PiP 和长期连播验收。本轮没有发布新安装包。

## 有意保持的范围

没有引入账号/评论/关注、跨作品刷剧流、静态热搜词、新播放器或新的缓存框架。应用手动检查更新作为独立改进保留后续评估。本轮 Go 实现依据实际协议和响应独立编写；来源及上游许可链接见 [UPSTREAM.md](../native/core/UPSTREAM.md#november-5-huangguo-api-and-line-selection)。
