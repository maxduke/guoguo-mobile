# 共用题材导航与站源请求反馈

本批参考 [HGhub 固定版本 `8665ffc`](https://github.com/Minireel/HGhub/tree/8665ffcaa553bc6eb1b52629fd91b35cc6e02678) 的题材快捷入口和线路状态呈现思路，将它们应用到共用界面，沿用森林绿、奶油白及暗色主题。没有复制其静态题材词、React 组件或状态框架。源协议、作品/分集身份、播放和下载行为保持现有契约。

## 题材导航

- 发现页提供题材选择；搜索空白页展示有限的真实题材快捷入口，更多题材可在面板中查找。详情标签可点击进入同题材页面，完整标签值仍有提示供阅读。
- 站源提供明确分类 ID 时按实际分类分页；普通标签仅精确匹配当前来源已保存资料的分类或标签。标题包含题材词不算标签匹配，也不以静态词冒充热门数据。
- 页面明确区分站源分类与已保存资料。初始缓存回退不会被标成刚取得的站源目录，已加载数量不表示全站总量。未增加跨站合并或自动搜索。
- 来源、分类、页码和请求 ID 固定在该页面。失败保留结果、重试原页；分页去重，离页取消匹配请求并忽略迟到结果。从其他站源的收藏/详情进入题材不会更改首页来源、原有分类选择或搜索词。
- 分类读取按站源合并进行中的请求，使详情标签、选择面板和既有剧库可以等待同一结果。继续沿用现有分类缓存和写入；题材页面不增加持久化目录分区或新的偏好。

## 站源选择

选择卡片从现有 64 条内存诊断中取最近前台请求，按请求时间选择，跳过取消、后台预取及输入联想。成功、部分结果、明确缓存和失败分别呈现；没有记录时显示未知。打开选择面板不探测站点，也不将目录读取成功表示成媒体可播。

当前站源的记录与手动重试使用紧凑操作区；输入搜索时收起该区，优先展示匹配站源。请求记录页可以只看、复制和清空选定站源，不影响其他站源记录。筛选、隐藏、收藏、原子保存和过期面板的归属检查继续保留。

普通手机采用两列状态卡，较宽窗口增加列数，大字体改为单列；卡片内容左对齐并统一高度，避免状态文字拥挤。题材选择面板将标题、输入和结果放在同一滚动区域，大字体及键盘打开时仍可操作。详情收起长资料后将已经滚出可见区域的选集入口带回，保留选定分集范围。

## 验证边界

局部回归覆盖十九站题材来源、精确匹配、来源隔离、分类请求共享、真实分类 ID、分页失败重试、迟到结果与取消、详情导航、缓存/部分结果语义、单站诊断清理、过期面板，以及窄屏大字体和键盘。

实际控件预览使用合成资料和中文字体，覆盖 390×844 浅色手机及 320×568、两倍字号的深色窗口，分别核对搜索、站源选择和题材页面。它们不代表真实站点数据、设备帧率或实体设备验收。

最终源码的 Flutter 全量 1035 项通过，零失败、零跳过，包含三项合成主机性能测量；51 项局部回归及实际控件预览通过。`flutter analyze` 无问题，215 个 Dart 文件格式复查与 `git diff --check` 通过。既有详情预览另覆盖手机、平板及小屏大字体的浅色和深色布局。

功能实现未修改 Go、原生插件或依赖。发布版本以 `pubspec.yaml` 和对应版本说明为准；iOS 与 Android phone/TV 集成由当前 PR HEAD 的 CI 单独验证。官方发布页入口不属于本次发布。
