# 黄果、红果播放修复（2026-11-15）

## 故障与参考来源

红果修改前，移动 API 能取得 18 条推荐和作品 `7592524831132765209` 的 12 集详情，但旧模型请求始终为空，网页与第三方路径也不能取得媒体。参考 [hongguo-drama 782fb21](https://github.com/jackotom/hongguo-drama/tree/782fb21cbddf1be46f88e97af5e788c99e30beae) 的 `app-source.js`、`playback-signature.js` 和当前接口回归，确认其已改用 `video_tab` GET 与真正的 Argus 551/Ladon 播放签名。旧签名族继续用于目录，不再用于播放。

黄果 [HGhub 当前版本](https://github.com/Minireel/HGhub/tree/cae4645ddfdd234dd9a5e90191007dac812360d9) 已撤下代码。对照其 [保留版本](https://github.com/Minireel/HGhub/tree/8665ffcaa553bc6eb1b52629fd91b35cc6e02678) 的播放和线路读取，并继续核对官网当前网页协议。真实同集对照中，`/api/videos/12/play?ep=1&page_texts=0` 仍返回 `status:1`，但媒体地址全部为空；新的 POST `/api/videos/12/episodes/1/playback` 返回正确作品、分集、播放方式、媒体地址和 CDN 请求头资料。新请求仍能通过已有 `/api/edge/request` 封装完成，正文为 base64 编码的空 JSON 对象，不需要引入官网加密会话或用户账号。

## 修改范围

- 红果优先一次当前 GET，使用 7.3.9.32 播放请求资料；仅 HTTP 200 空正文允许一次旧接口 gzip POST，并使用该接口的 7.4.3.32 请求资料。签名绑定最终 query、发送的实际正文及本次时间。保留手机兼容的 `device_level=1` 和 AVC/HEVC 筛选。
- 两次模型请求共用 12 秒期限，仍受原调用取消/总期限约束；一次成功不探测旧接口。最多两次注册，明确拒绝/取消立即停止；备用注册临时失败时可保留原身份完成唯一旧请求。移除旧的八次模型恢复阶梯和主机轮换，保留旧请求的独立 HTTP/2 连接。
- 新接口按 `data.video_model_data[分集 ID]` 精确选集，也兼容直接的 `data[分集 ID]`；继续复用现有模型解析、缺加密资料恢复、缓存过期及媒体准备。新 GET 不额外请求后续分集；只有上游已返回且匹配既有前瞻身份的模型才能进入现有小缓存。
- 黄果使用新的 POST 分集播放接口，校验 `id`、`ep`、`manifest_method=GET` 和 `streams.main`。沿用现有自动两条线路/16 秒读取上限、手动固定线路、详情身份和 HLS 代理。
- 黄果 `x-cdn-auth` 与 `x-cdn-app` 只保存在当前媒体凭证中，按返回的播放列表/分片开关应用；仅同一个流来源可接收，跨来源跳转移除，不进入账号 Cookie 或页面缓存。初始及嵌套播放列表都能使用凭证，未要求凭证的分片不携带它。拒绝让接口指定任意请求头名称。
- 参照 HGhub 补充固定官方发布页 `https://huangguoai.pages.dev/`。主入口无可用线路时，读取其同来源脚本里的域名/子域数组；只解析数据，不执行 JavaScript。发现总期限八秒，拒绝重定向，继续使用现有公网 DNS 检查和 API 身份校验；失败保留已有线路，手动选择不被覆盖。

后台下载仍生成可独立使用的资源图。仅播放列表需要 CDN 头时，核心读取并内联播放列表，后台资源不携带临时头；恢复时重新取源。若服务端要求分片也携带这些临时头，现有后台传输的共享请求头不能保证逐资源/跳转隔离，因此明确拒绝此类后台计划，在线播放仍通过核心代理支持。

## 已验证与边界

独立上游 Node 生成的 18 组 Argus/Ladon 向量全部通过，包括无正文、JSON、gzip、负随机字段及大时间戳；原目录签名向量也保持通过。受控回归覆盖新旧接口次数、错集、非空错误不恢复、拒绝/取消、注册临时失败、模型缓存、线路发布页和 CDN 请求头的初始/嵌套 HLS、跨来源跳转、后台凭证边界。

最终 `go test ./... -json -count=1` 共 824 个测试/子测试通过，零失败；8 项既有可选联网巡检未启用。真实 FFmpeg 合成媒体回归已执行。`go vet ./...`、相关协议/身份/线路/媒体凭证竞态检查与 Go 格式、差异检查通过。完整回归日志为 `/tmp/guoguo-playback-all-verified.jsonl`，竞态日志为 `/tmp/guoguo-playback-race.log`。

真实移动 API 抽查：

- 红果：18 条推荐、上述作品的 12 集详情、首集 HTTP 206/1024 字节；完整 CENC 媒体准备与 FFmpeg 全集解码通过；同一个移动客户端连续前三集均取得 HTTP 206/1024 字节。
- 黄果：使用官网当前公布的内容线路，`都市` 搜索 24 条、作品 `huangguoai:2046` 详情 15 集、首集 HLS 媒体 HTTP 206/1024 字节；核心代理读取、完整 MP4 准备与 FFmpeg 全集解码通过；同一个移动客户端连续前三集均取得 HTTP 206/1024 字节。线路只写入临时测试会话，没有在应用中固定这个会轮换的域名。

本机对 `huangguoai.ai`、`huangguoai.pages.dev` 的直接 TLS 连接仍失败；备用发布页路径由受控回归验证，未声称本机已实际完成自动线路恢复。官方入口的另一网络读取可取得当前公布内容线路，不等于所有网络均能访问入口。

这些检查是实现阶段的主机协议和解码验证，不代表 iPhone/Android/TV 上已通过起播、切集、画中画、后台恢复或长时间连播。此次没有修改 Flutter/原生桥接接口；版本身份、安装包和校验值以本版本标签对应的发布工作流与 GitHub Release 为准。
