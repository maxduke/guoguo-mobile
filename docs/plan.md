# 0.3.1 实施计划

基线：v0.3.0 已发布，用户初步真机测试无明显问题。

## 本轮范围

- [x] 下载可靠性：重试保留旧文件与可复用分片；新资源规划失败不破坏旧任务；保存失败原因；清理未登记的任务残留；提示存储写入失败。
- [x] 追剧入口：从“接着上次看”直接续播；详情页显示分集下载状态；支持选择集数范围和“接下来 10 集”。
- [x] 连载更新：分集缓存记录刷新时间、过期刷新与离线回退；详情手动刷新；收藏检查新集并显示提示。
- [x] 播放观测：记录解析、媒体准备、播放器就绪及实际开始播放的耗时，保留有限条本地诊断；加载阶段对用户可见。
- [x] 验证：下载失败/重试与旧文件保留、缓存过期/离线/并发、续播和范围下载、诊断脱敏与容量上限；静态检查及现有回归。

## 验收边界

- 不移动或重用 v0.3.0 标签。
- 本轮不改为流式解密；先获得可比较的耗时数据。
- 空间管理的按剧统计/排序属于后续版本；本轮先补足失败提示与残留回收。
- 播放诊断仅存设备本地，不记录媒体 URL、密钥或账号信息。
- 后台下载和真实首帧耗时需要 iOS 真机复核；自动化通过不等于该项验收完成。

## 进展

- 已完成本轮实现，版本准备为 `0.3.1+6`，更新说明在 `releases/v0.3.1.md`。
- 下载重试保持原任务 ID 与已完成文件。兼容性采用保守判断：资源布局、密钥、清单或已完成分片 URL 变化时，不混用旧分片；保留文件并提示删除旧任务后重新下载。
- 分集缓存有效期为 6 小时；同一部剧的并发请求复用。自动刷新失败可回退缓存，手动刷新即使共用请求也报告失败。新增提示按分集 ID 对比，打开详情后确认已查看。
- 本地诊断最多 30 条；分别记录准备阶段与本次启动等待。以播放进度前进作为开播近似指标，尚未获得精确首帧测量。
- 验证记录：全量 43 项 Flutter 测试（含 FFmpeg 回归）通过；随后下载恢复与缓存并发的 11 项专项测试通过，包含 2 项追加用例，共覆盖 45 项测试。静态检查、格式检查、版本/更新说明校验、diff 检查均通过。可选截图生成测试本轮未运行。
- [ ] 发布后按 `docs/ios-device-checklist.md` 的 0.3.1 清单复核后台下载、磁盘不足、真实续播与启动耗时。
- 交付：实现与本地验证完成，使用 `v0.3.1` 标签流水线发布。最终交付状态见 [Release](https://github.com/maxduke/guoguo-mobile/releases/tag/v0.3.1) 及其构建信息中的 CI 链接；上述真机复核仍需独立完成。
