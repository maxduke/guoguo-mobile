# iPhone / iPad 真机验收

安装当前 CI 成功提交对应的自签 IPA。记录设备型号、系统版本、签名方式及 commit SHA。

1. 首次启动，红果/黄果/黄豆分别加载目录、打开详情并播放，覆盖不同媒体类型。
2. 选集、上下滑、自动下一集、拖动进度、切换清晰度；离开播放器再进入验证续播。
3. 浅色/深色、iPhone 横竖屏、iPad 分栏及大字体，检查遮挡与溢出。
4. 收藏两站同名剧，确认分别存在；导出并在另一台设备导入，确认记录合并及续播位置。
5. 分集/整剧下载、暂停/恢复、失败重试、删除，下载完成后关闭网络验证真正离线播放。
6. Wi-Fi 转移动网络，确认下载与下一集预缓冲遵守各自开关；手动暂停的任务不自动恢复。
7. 锁屏/切换应用/系统回收进程，恢复应用后核对任务与播放记录；强制关闭与系统回收分开记录。
8. 进入 PiP、返回全屏、暂停恢复、下一集，确认无双音轨、黑屏或进度回退。
9. Sony 电视注明型号及接收软件，在同一 Wi-Fi 下测试 Google Cast；如支持 AirPlay / DLNA，分别记录发现、播放、暂停与结束结果。
10. 单独记录首次加密分集的准备时间、普通分集首帧时间、预缓冲后的切集等待。

问题反馈请提供上述环境、站源、剧名/分集、步骤和现象；不要粘贴播放密钥、账号凭证或包含签名参数的完整媒体 URL。
