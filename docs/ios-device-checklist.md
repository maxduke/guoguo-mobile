# iPhone / iPad 真机验收

本清单针对 [当前产品规格](product-spec.md)，按全新安装验证。安装当前 CI 成功提交对应的自签 IPA，记录 commit SHA、构建号、设备型号、系统版本和签名方式。旧版验收要求保留在 [历史清单](archive/ios-device-checklist-history.md)，不作为当前迁移或旧备份兼容要求。

自动化、iOS 编译和主机性能样本均不能代替以下设备结果；本页列出待执行场景，不表示已经通过。每项记录实际步骤、通过/失败/未执行、现象和对应环境。

## 布局与无障碍

- iPad 从全屏缩到分屏，再恢复全屏：宽且有足够高度的窗口使用侧栏，窄窗口和矮横屏使用底部导航；保留当前标签、站源、下载筛选、搜索输入/结果及有效滚动位置。
- 小屏开启系统大字体，切换明暗主题和横竖屏；多个启动、离线或保存提示同时出现时，提示区可滚动，重试操作与主体内容仍能使用。
- 键盘打开时查看搜索空状态和失败提示，滚动到重试按钮并重试；收起键盘后继续浏览结果。
- VoiceOver 浏览发现页和剧集卡片，详情动作只朗读一次完整剧名，收藏动作包含作品名称；检查详情、收藏、导航和明确的播放/暂停及相邻分集入口。
- 辅助导航启用后播放控件保持可达；大字号、横屏、刘海和 Home 指示条不遮挡操作。普通横滑预览进度、长按加速及触摸取消分别验证，长按移动不跳进度。
- 导出记录备份，在文件准备期间缩放 iPad 窗口，确认分享面板位于当前窗口内；准备期间进入其他页面或退出设置，不应迟到弹出分享。返回设置后可以重新导出。

窗口、语义和分享参数已有自动化回归；系统面板、实际读屏和设备手势体验仍需真机验证。

## 找剧与记录

- 首次启动分别检查目录、榜单/推荐、详情及播放，覆盖红果、黄豆/黄果和其他实际使用来源。能力标签、常用/隐藏管理与请求健康反馈准确；十八站联网搜索与黄豆缓存筛选分别验证，黄果搜索限定 AI 子源。
- 在剧库改变分类/排序，分页失败后重试；搜索输入法组合、联想、提交、翻页和返回详情后恢复结果/位置。切换来源或退出后，旧请求不能覆盖新页面。
- 收藏两站同名剧，身份分别保留；追剧最近续播及普通记录卡片恢复真实分集和位置，已播完进入下一集、连载等待更新和明确完结重播分别验证。
- 刷新分集失败保留已缓存内容。离线下载缺少中间一集时不自动跨过，仍能主动选播后续已下载分集。
- 红果同系列联网补全、按季排序、新季提醒基准/检查/已读及退出取消分别验证；没有收藏也能检查已开启的提醒。
- 红果搜索多季剧：首屏可打开结果，“加载更多”后新增季数且不丢旧结果；查询中改词、切源、退出后旧页不能覆盖。重启后重新搜索能继续查找，续搜过期时重试保留已显示资料并从首屏重新请求。受三页/二十秒限制的新季检查不把未完整结果当作首次基准。
- 导出 v2 收藏、历史和新季提醒备份，在另一台设备预览并导入，检查合并结果及续播位置；模拟写入失败，原有记录保留，下载文件不属于备份范围。

## 手机播放与生命周期

- 0.19.0 剧库提前加载：Wi-Fi 停稳只加载当前分类下一页，蜂窝、断网和关闭开关时不预取；切源/分类、离页或后台取消。预取中手动刷新立即接管，晚到结果不回填、不跳页。清缓存后刷新黄果三个栏目，复制站源诊断检查联网尝试与失败类型。

- 分别测试普通 MP4、在线 HLS、需要准备的加密媒体和完整下载视频。红果提前开播与完整准备分别核对画面、声音和进度同时推进；不能只以进度条认定画面正常。
- 选集、快速上下滑、自动下一集、拖动、倍速和清晰度；快速连续切集只安装最后一次有效选择，上一集结束事件不跳过新集。检查预取及 Wi-Fi/蜂窝偏好。
- 红果关闭提前开播、开启预缓冲，在 Wi-Fi 下连续自动播放至少三集并手动切换：完整本集开始播放后下一集提前完成准备，换集复用缓存；记录打开/关闭预缓冲时的实际等待及诊断 waitMs。准备中关闭开关、Wi-Fi 转蜂窝、退出或普通后台应取消下一集并保留当前集；提前开播、PiP、慢网和超过一分钟仍未准备完成分别复测。
- 主动暂停超过十秒不自动恢复；准备/恢复中返回、切集或后台，不出现旧视频迟到开播、进度回退、双音轨或未释放的任务。
- 系统自动锁屏设为 30 秒，前台全屏播放和缓冲时持续亮屏；暂停、播完、播放错误、退出和画中画后正常自动锁屏。独立侧载与 LiveContainer 分别验证，回到前台及切集后再次等待超过锁屏时限。
- 连播至少 30 集红果完整准备视频（关闭提前开播），再检查普通在线 MP4/HLS、下载视频及开启提前开播的红果。记录实际画面/声音、掉帧、内存及设备温度；暂停、快速切集、退出重进后任务数量和内存应回落。自动化的任务回调检查不能代替设备上的渲染和能耗结果。
- 离开再进入、重启应用、后台返回以及锁屏后核对分集、进度、暂停意图和已确认播完状态。
- 进入 PiP、返回全屏、暂停恢复和切集，确认实际系统窗口、音画、进度和后台策略；把 PiP 与普通后台播放分别记录。
- 0.17.2 定位/锁屏复测：关闭“提前开播（实验）”，在黄果分别前拖到未播放位置、回拖到近期位置、连续拖动三次、定位中暂停/切集；锁屏 5 秒及 30 秒后恢复。每种条件至少五次，核对目标位置、暂停意图、媒体是否重新安装，以及操作到实际正常画面的耗时。诊断中的定位完成时间不代替画面恢复时间，详见 [实现和验证范围](playback-seek-resume.md)。

## 下载与空间

- 同一剧准备完成、下载中、暂停和失败条目，核对收起/展开、筛选、排序、分集操作及滑动删除；两站同名/同 ID 不合并。
- 选定范围、接下来若干集和整剧下载核对队列；确认后刷新分集不改变已选范围，也不自动加入新增分集。
- 暂停、断网重试、签名地址刷新时保留身份一致的完成分片；规划失败或媒体结构/密钥改变时保留原文件与可重试任务。
- 下载完成并整理成功后断网播放。前台整理前不声称完整离线；HLS 整理期间删除不能破坏正在使用的输出。
- Wi-Fi/蜂窝、锁屏、系统回收进程后检查任务恢复；用户强制关闭单独记录，手动暂停不自动恢复。
- 下载空间管理多选删除并取消/确认，核对其他剧、收藏和历史保留；批量重试有一项失败时其他项仍执行。
- 设置核对各存储范围、未知值及清理影响。播放、投屏或下载时清理临时/播放缓存，活跃资源不被删除，用户记录及页面已持有的目录不被误清。
- 模拟空间不足、删除失败与恢复失败，检查明确提示、已有文件和重试入口；记录系统下载临时文件与应用可测容量的差异。

## 设备投屏

记录电视型号、接收软件名称/版本、协议、Wi-Fi、VPN/网络接口和媒体类型。手机与电视在同一网络，允许本地网络访问。AirPlay、Google Cast 和 DLNA 分别验证，不用一种协议的结果推定另一种通过。

- 从统一设备入口检查发现、取消、超时重试、在线 MP4/HLS 和下载视频；非零位置以及原来暂停时投屏，核对电视状态与单一播放端。
- Cast/DLNA 收起面板后继续控制，电视遥控暂停/定位后观察已确认位置；结束后手机保留位置和暂停意图。无进度信息不保存为零，结束失败不自动手机开播。
- 连接期间退出、断网、关闭接收器、重复进入时没有旧加载或后台残留。Cast/DLNA 手机中转保持前台，后台能力另行记录。
- AirPlay 使用独立原生界面，通过系统列表选择电视；音画、原生拖动/暂停、连续三集自动/手动换集、最后一集停止与关闭自动连播分别验证。
- 使用曾报告失败的红果作品及同一安卓电视/蓝莓版本复测换集：旧地址保留至新集实际推进，暂停后下一集仍暂停；准备/加载失败能重试同一分集，当前正常视频不被停止。
- AirPlay 后台/锁屏连播与返回状态分别验证。退出先停止原生使用再释放中转；旧页面不能停止新会话。系统仍选电视时手机保持暂停，选回 iPhone 后音画、分集与位置一致。
- 投屏切集时切换网络触发手机缓存裁剪，投屏当前/下一集资源仍可用；结束后释放。慢网络、取消、准备失败和仅接通音频的接收器分别记录错误阶段。

## 性能采样

主机样本和已采用的局部优化见 [性能基线](performance-baseline.md)。设备采样使用 profile/release 构建，记录设备/系统、提交、来源/分集、网络、缓存冷/热、目录/记录/真实分片任务数量。冷启动与热启动、首次播放与已预备切集分别采样，不把有缓存的结果称为首次安装性能。

每种条件至少重复五次，保存各次数据和中位数。测量场景与起止点要固定：

| 项目 | 起止与证据 |
| --- | --- |
| 启动 | 启动操作至本地首屏可用，再单独记录联网内容；避免把源响应慢合并成界面构建耗时。 |
| 起播 / 续播 / 切集 | 用户确认操作至实际第一幅正常画面和声音，必要时以录屏对齐；记录资源准备和缓冲阶段。诊断的首次进度前进只作近似，不能替代精确首帧。 |
| 大目录 / 下载队列 | 在真实目录及分片任务下筛选、排序、滚动与批量操作；用 Flutter profile Timeline 观察帧和主线程暂停。 |
| 持久化 / 内存 | 记录保存、目录写入、恢复后的耗时与文件容量；用 Xcode Instruments 的 Time Profiler / Allocations 检查 CPU、分配与退出后资源释放。 |
| 能耗 / 后台 | 用 Instruments 能耗工具对比完整准备、提前开播、预取及不同投屏协议；条件相同，记录持续时间、后台策略和系统资源限制。 |

目录/分集硬容量限、SQLite、播放器替换和跨页面会话继续依据真实工作集及这些结果决定；没有样本时保持未验收，不预先扩大架构。

问题反馈提供环境、站源、分集、步骤和现象，以及安全错误类型/整数码；不要粘贴密钥、账号凭证或包含签名参数的完整媒体 URL。
