- 安装 `0.11.4+26` 对应构建，红果开启提前开播，从头播放此前必须拖动才恢复的分集。保持不操作，检查画面、声音和进度同时连续推进，不能只记录进度条。
- 手机竖屏／横屏、平板、完整画面／裁边铺满分别检查方向和比例；再测试完整准备、本地 MP4、普通 HLS，覆盖原生渲染路径差异。
- 暂停与恢复、手动拖动、切集、退出重进、PiP 交接及后台返回，确认无额外跳转、旧任务自动播放或画面方向变化。

## 0.11.3 开头卡顿与站源选择

- 设置 → 播放诊断开启“提前开播”，红果从头播放，检查出画面后声音和进度持续推进。对比修复前卡在开头的分集，记录启动等待和是否出现完整准备回退。
- 播放中主动暂停超过十秒，确认不自动恢复或开播；如开头连续十秒无进度，确认完整准备后保留位置并续播。
- 快速切集、返回、进入及关闭 PiP，确认旧渐进任务停止，进度和暂停状态沿用。
- 点击当前站源，检查网格直接选择、名称搜索及切源后清空原查询；收藏／历史和下载可重新选择“全部站源”。检查小屏、大字体、横屏及键盘弹出时仍能点选。

## 0.3.1 优先回归（待发布后实机执行）

- 从首页及追剧页点击“接着上次看”，直接进入上次分集并恢复进度；断网时也检查已缓存/已下载的剧集。
- 在详情页检查“已下载 / 下载中 / 已暂停 / 失败”标记；选择任意起止集数、“接下来 10 集”和整部下载，核对队列范围与重复分集处理。
- 暂停和断网后重试分片下载，确认已完成分片未丢失；资源接口失败时原任务仍在。资源结构、密钥或已完成资源地址改变时，应提示保留旧文件并重新下载，不能混用不同资源。
- 重启后核对失败原因；模拟设备空间不足时应给出空间检查提示。区分进程被系统回收与用户强制关闭。
- 收藏页“检查新集”及详情“刷新分集”能获取更新；断网或更新失败时保留缓存，手动刷新有失败提示。打开分集列表后“新增”提示应清除。
- 设置 → 播放诊断：对比首次播放、已预备切集与本地播放；记录最多 30 条，复制内容不包含剧名、地址、密钥。进度首次前进只是启动近似指标，不是精确首帧测量。

## 0.2.1 优先回归

- 黄果、黄豆榜单显示小封面；从榜单进入详情、收藏、播放及下载后，各页面封面一致。旧历史和旧下载记录首次联网时也应补齐，加载成功后断网再查看。
- 连续单击视频空白区域，应立即显示、隐藏控件；暂停使用控制栏的播放/暂停按钮。
- 左右拖动视频应出现目标时间，松手后只跳转一次；向左快退、向右快进，上下滑动仍为切集。
- 长按不移动进入 2 倍速，松手恢复所选倍速；长按后左右滑动转为进度预览，松手跳转。中途切到后台再返回，不能卡在 2 倍速。
- 打开倍速菜单后等待 3 秒，菜单与控件仍可操作；选择或关闭后恢复自动收起。
- 在 iPhone 小屏与 iPad 上检查榜单小封面占位、长标题及手势提示无溢出。

## 0.2.0 优先回归

- 红果向底部滚动，确认自动加载、数量持续增加；刷新和重启后仍能继续，不把已加载数量当作全站总量。
- 黄果、黄豆列表封面出现后关闭网络，再检查缓存封面能否显示。
- 默认播放器保留完整画面，标题和控制栏隐藏；轻点呼出，播放中等待 3 秒自动收起。“更多”内切换裁边铺满、横竖屏、画中画、投屏、清晰度和锁定。
- 慢拖观察画面是否跟手；快速连滑多集，确认只播放最后选定的一集；滑回上一集检查缓存复用，已结束的上一集应从头播放。
- 当前集播放几秒后切下一集，比较预加载前后等待；Wi-Fi/蜂窝切换时确认预加载遵守设置。
- 拖动进度条时预览时间，松手后跳转；刘海、Home 指示条与横屏下的控制栏应在安全区域内。

## 完整验收

1. 首次启动，红果/黄果/黄豆分别加载目录、打开详情并播放，覆盖不同媒体类型。
2. 选集、上下滑、自动下一集、拖动进度、切换清晰度；离开播放器再进入验证续播。
3. 浅色/深色、iPhone 横竖屏、iPad 分栏及大字体，检查遮挡与溢出。
4. 收藏两站同名剧，确认分别存在；导出并在另一台设备导入，确认记录合并及续播位置。
5. 分集/整剧下载、暂停/恢复、失败重试、删除，下载完成后关闭网络验证真正离线播放。
6. Wi-Fi 转移动网络，确认下载与下一集预缓冲遵守各自开关；手动暂停的任务不自动恢复。
7. 锁屏/切换应用/系统回收进程，恢复应用后核对任务与播放记录；强制关闭与系统回收分开记录。
8. 进入 PiP、返回全屏、暂停恢复、下一集，确认无双音轨、黑屏或进度回退。
9. Sony 电视注明型号及接收软件，在同一 Wi-Fi 下测试 Google Cast；如支持 AirPlay / DLNA，分别记录发现、播放、暂停与结束结果。
10. 单独记录首次加密分集的准备时间、普通分集首帧时间、预缓冲后的切集等待。

问题反馈请提供上述环境、站源、剧名/分集、步骤和现象；不要粘贴播放密钥、账号凭证或包含签名参数的完整媒体 URL。

## 0.4.0 下载与空间管理

- 同一部剧准备已完成、正在下载、暂停和失败的不同集数，核对任务页状态、进度、失败原因与筛选数量。
- 在“按剧空间”确认各集归并为一部剧，默认按占用排序；两站同名/同 ID 剧目不能合并。下拉后统计与已保存文件一致，系统下载临时文件不计入。
- 多选两部剧删除，确认提示剧数/集数，取消时不改文件；确认后所有状态的选中任务被清理，其他剧、收藏及观看历史保留。返回设置页核对占用同步。
- 下载进行中暂停/恢复，断网再联网，切换 Wi-Fi/蜂窝以及锁屏恢复；观察排队、自动重试、失败与整理状态是否与系统任务一致。
- 对多个失败任务批量重试，让一项保持失败，确认其他项继续、结果报告正确，已完成和手动暂停项不被重试。
- HLS 整理期间尝试删除，不应破坏正在整理的输出；整理完成后可以删除。观察系统临时文件是否最终释放。
- 使用 iPhone 小屏、大字体、深色模式及 iPad 复核，已完成集数仍能直接离线播放和按原集数顺序切换。
