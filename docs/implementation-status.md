# 当前实现状态

本文件记录实现与验证的区别。当前优先 iPhone / iPad，Android 手机验证后置；用户已有 Sony 安卓电视，具体型号尚未提供。

## 已实现的源码路径

- Flutter 手机和平板页面、暖白/墨绿与深色主题、站源选择、搜索与分类。
- 三站设备内 Go 核心、分集解析、真实站点榜单；红果联网搜索。
- 收藏、观看历史、续播、跨站汇总、记录导出与导入预览。
- 原生播放器、上下滑切集、选集、倍速与长按加速、清晰度选择、画中画与 AirPlay 入口。
- Google Cast 与 DLNA 设备发现、在线媒体中转、播放/暂停/结束投屏。
- 后台文件任务、分片资源规划、分集/整剧下载、暂停/恢复、失败重试、删除与空间统计。
- 下载完整后将需要处理的媒体在前台整理为本地 MP4；处理成功后才显示完成并允许离线观看。
- Wi-Fi 默认下载规则、网络偏好、断网缓存浏览。
- GitHub macOS 无签名 iOS 构建与个人签名用 IPA 打包流程。

## 已执行的验证

- 0.1.1 修复验证：合成 CENC MP4 复现旧版 HLS 参数误传失败，修复后解密并完整解码成功；真实红果样例（目录 32 部、样例 27 集）的单集准备与整集解码成功。该验证在 Linux FFmpeg 上执行，仍需 iOS 更新后验收。
- 播放区域新增竖屏、横屏、平板尺寸变化测试；默认等比例铺满，可切换完整画面，并提供隐藏页面栏位的全屏按钮。
- 离线 HLS 使用 `.bin` 分片的回归覆盖新版 FFmpeg 的扩展名检查，只有应用生成的本地清单放宽该检查。

- 使用与应用相同的 Go 移动接口，实际获取红果 37 部、黄豆 50 部、黄果 512 部目录。数量是该轮加载返回量，不代表站源总量。
- Go 移动桥接与参考核心测试通过。新增离线资源图测试覆盖相对路径、密钥、本地清单、重复分片和无效协议。
- Flutter 手机/平板浅深色布局及数据行为的 10 项测试通过；另有可选预览生成检查，截图在 screenshots/。最终交付以当前 HEAD 的 CI 为准。
- 单集媒体请求实测：红果样例 63 集、媒体 HTTP 206（加密 MP4）；黄豆样例 6 集、HLS HTTP 200；黄果样例 1 集、HLS HTTP 200。每次只读取首段数据，不代表完整解码已验证。
- iOS 编译结果以当前 HEAD 的 GitHub Actions 为准；本文不提前声称成功。

## 仍需真机验证或完善的限制

1. **iOS 真机未验收**：Linux 无法证明 iPhone / iPad 上的播放、PiP、后台下载或投屏成功。需要安装自签 IPA 后实测。
2. **加密分集的首帧等待**：当前将需要额外处理的单集准备为兼容 MP4 后再开播，首次播放可能等待整个分集传输完成；后续应验证流式处理以缩短等待。
3. **联网搜索**：黄果和黄豆当前明确提示仅本地筛选，尚未接入其联网搜索，不能将本地结果标作联网成功。
4. **投屏保持前台**：Google Cast / DLNA 当前通过手机中转资源，界面提示保持果果前台。发现成功不代表所有编码与电视组合都能播放；自签环境下的本地网络/组播权限也需验证。
5. **投屏控制**：已实现播放、暂停与结束；投屏端选集、精确进度交接及自动连播尚需完善。当前关闭投屏面板会结束会话。
6. **离线整理**：后台负责资源传输，媒体整理在回到应用后执行。不承诺 iOS 强制关闭应用后持续执行媒体处理。单个资源若不支持断点恢复，会重传该资源，已经完成的分片可保留。
7. **分片格式边界**：离线资源规划暂不支持含独立音轨的主清单和直播清单，并会明确报错。
8. **图像与推荐**：封面失败有回退样式；HEIC 封面解码仍需设备验证。当前展示站源目录与编辑式空白区域，没有个性化推荐算法。
9. **Android**：保留工程和桥接构建入口，当前没有 Android 安装包或真机验证结论。

以上不是删减已确认的最终产品目标，而是说明当前开发版本可验收的范围。不得以此文档或一次目录请求成功代替完整产品验收。
