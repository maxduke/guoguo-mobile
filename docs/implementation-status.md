# 当前实现状态

本文件记录实现与验证的区别。当前优先 iPhone / iPad，Android 手机验证后置；用户已有 Sony 安卓电视，具体型号尚未提供。

## 已实现的源码路径

- Flutter 手机和平板页面、暖白/墨绿与深色主题、站源选择、搜索与分类。
- 十六站设备内 Go 核心和分集解析；所有站源开放榜单／推荐／目录入口，黄豆以外的十五站支持联网搜索，黄果仅搜索 AI 子源。
- 收藏、观看历史、续播、跨站汇总、记录导出与导入预览。
- 原生播放器、上下滑切集、选集、倍速与长按加速、清晰度选择、画中画与 AirPlay 入口。
- Google Cast 与 DLNA 设备发现、在线媒体中转、播放/暂停/结束投屏。
- 后台文件任务、分片资源规划、分集/整剧下载、暂停/恢复、失败重试、删除与空间统计。
- 下载完整后将需要处理的媒体在前台整理为本地 MP4；处理成功后才显示完成并允许离线观看。
- Wi-Fi 默认下载规则、网络偏好、断网缓存浏览。
- GitHub macOS 无签名 iOS 构建与个人签名用 IPA 打包流程。

## 0.11.2 恢复与后台交接

有限恢复预算、恢复期间的互斥与迟到线路释放，以及播放意图、800 ms 自动 PiP 交接、后台挂起和完整准备后的恢复已移入独立控制器。兼容恢复会核对交接期间的最新意图，关闭 PiP 不再被旧的继续播放请求覆盖。页面提供原生播放效果和 UI 回调；系统事件适配、实际兼容视频准备、观看记录和预取调度仍保留在页面。范围与验证见 [协调整理记录](playback-coordination-2026-10-03.md)。

## 0.11.1 播放会话整理

将资源准备、前台接管、缓存有效期、清晰度与完整准备策略、资源释放及原生播放源交接收进独立会话控制器。播放轮次校验阻止迟到准备结果进入新的播放，原生设置串行执行并跳过过时请求，设置失败不会阻塞后续恢复。补齐备用资源被覆盖、移出保留范围及关闭后提交时的释放。页面继续负责控件、播放意图、恢复预算与生命周期／PiP 事件，本轮没有完成全部协调逻辑的抽取。详细范围和验证见 [会话整理记录](playback-session-2026-10-03.md)。

## 0.11.0 首段预取

下一集后台只解析地址及预取有限首段数据，选中时复用缓存，再按现有设置准备加密媒体。每个会话的媒体预取读取预算为 4 MiB、6 秒、8 次请求；网络偏好、前台接管、取消和释放均有回归。播放诊断新增首段字节数及预取耗时，原生协议同步为 3。完整边界及验证见 [首段预取记录](media-prefetch-2026-10-03.md)。

## 0.8.0 新增站源

- 剧果、野果、帝果通过共同移动接口接入在线分类、分页目录／搜索、详情、分集与播放解析，旧三站身份不变。

## 0.6.0 融合第一批

- 详情底部常驻开始／继续观看及下载，手机单一滚动区域、平板分栏；返回播放后更新续播状态。
- 选集新增定位当前、选中语义、原始集数分页；刷新列表保留用户所选范围。
- 播放备用线路与一次重新解析，每集最多三次自动恢复；手选清晰度不自动降档。前台播放连续 20 秒无进度才触发卡顿恢复，暂停、拖动、菜单和后台不计入。
- 倍速和自动连播偏好持久化；加载／失败时保留返回和选集入口。
- 预加载等待至少 2 秒播放、至少 5 秒连续缓冲并进入后半段或最后 45 秒；本地播放不要求网络缓冲。失败冷却 30 秒，未使用的远程地址缓存超过 2 分钟重新解析。
- 加密分集仍使用完整准备路径，本轮没有实现受字节预算限制的流式预取，也没有替换媒体内核。详细范围和验证见 [融合实施记录](app-fusion.md)。

## 仍需真机验证或完善的限制

1. **iOS 真机部分验收**：用户已确认红果能播放，0.2.0 播放体验改善；用户确认 0.3.3 黄果分类封面修复后测试无问题；本轮 0.4.0 空间管理及后台暂停/删除仍需设备回归。PiP、后台下载和投屏也需真机验证。Linux 测试不等于设备性能验收。
2. **加密分集的首帧等待**：默认仍将需要额外处理的单集完整准备后再开播。0.7.0 增加默认关闭的提前开播实验，尚未完成真机首帧、内存和耗电对照，不能保证任意跳集立即播放。
3. **联网搜索**：黄果联网搜索仅覆盖 AI 子源；黄豆仍仅本地筛选，不能将本地结果标作联网成功。
4. **投屏保持前台**：Google Cast / DLNA 当前通过手机中转资源，界面提示保持果果前台。发现成功不代表所有编码与电视组合都能播放；自签环境下的本地网络/组播权限也需验证。
5. **投屏控制**：已实现播放、暂停与结束；投屏端选集、精确进度交接及自动连播尚需完善。当前关闭投屏面板会结束会话。
6. **离线整理**：后台负责资源传输，媒体整理在回到应用后执行。不承诺 iOS 强制关闭应用后持续执行媒体处理。单个资源若不支持断点恢复，会重传该资源，已经完成的分片可保留。
7. **分片格式边界**：离线资源规划暂不支持含独立音轨的主清单和直播清单，并会明确报错。
8. **图像与推荐**：封面失败有回退样式；HEIC 封面解码仍需设备验证。当前展示站源目录与榜单，没有个性化推荐算法。
9. **Android**：保留工程和桥接构建入口，当前没有 Android 安装包或真机验证结论。

以上不是删减已确认的最终产品目标，而是说明当前开发版本可验收的范围。不得以此文档或一次目录请求成功代替完整产品验收。
