## 当前能力边界

目录/分集缓存尚无新增硬容量限，真实离线工作集和设备负载仍需采样。SQLite、播放器替换、多站搜索预算、跨页面投屏及其他协议队列按 [性能报告中的取舍](performance-baseline.md#当前取舍) 继续评估。高级交换和来源适配保留实际调用与媒体契约，不按代码年龄删除。

缓存无法联网刷新时只能显示已保存资料；站源的实际内容、授权和资源有效性取决于请求结果。下载传输与媒体前台整理分别受系统和设备资源约束，部分文件未完成时不声称可离线观看。
