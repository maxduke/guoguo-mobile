## 结论

当前处理：默认停用 **皮果、牛果、超果、爽果**，保留来源身份和手动恢复入口；**帝果继续启用**。手机 `0.19.8(48)` 能播放帝果，但全部封面缺失，且用户使用代理分流，因此主机连接失败不能作为帝果停用依据。爽果虽然在主机干净会话中可取得目录和媒体，手机却连目录都无法加载；先补浏览器兼容连接、将联网搜索降级为本地筛选，真机通过前仍默认停用。

其余待办：**观果优先修复**，已验证官方新接口与媒体地址，不应删源。**黄果只处理失效的视频子线路，保留旧黄果和 AI**。这两项没有混入本次五个来源的修复范围。

媒体阶段按当前 App 实现统计：13 源样本链路通过、黄果部分可用、5 源失败。观果的官方新 H5 验证另列，未将尚未接入 App 的修复算成现有功能通过。

## 需要修复的具体位置

### 观果：已有明确修复契约

现有 `fetchGuanguoDetail` 请求 `/drama/home/shortVideoDetail`；HTTP 200、业务 code 200 但 data/title 为空。当前[官方 H5](https://h5.drama.9ddm.com/h5/) 使用 `/drama/play/h5/detail`，参数包含 `deviceId`、`oneId`、`os_type=2` 和选集时的 `playOrder`。

对本轮旧接口失败的相同三个 ID，新接口的作品 ID 均匹配，返回 81、63、88 集。`h5PlayUrl` 是 base64 信封，前 16 字节为 IV，余下部分按 AES-CBC/PKCS7 解密，密钥来自 base64 `h5PlayKey`；三个样本均解出 `super/high/normal` 清晰度地址。首个样本还取得 HTTP 206、1,024 字节 MP4 数据。另核对第一和第二集的请求返回不同播放数据。

实现应沿用已有作品身份，接入当前详情字段，并在选集时按 `playOrder` 解析、核对身份和失败状态；不必预先请求所有分集。需要覆盖当前 H5 字段、选集差异、播放信封解码、空数据及请求失败。相关代码：[provider_duanju_api.go](../native/core/internal/app/provider_duanju_api.go) 的 `fetchGuanguoDetail`、`guanguoEpisodeURL`。相邻 `guoapp` 仍是旧接口，不能直接照搬。

### 牛果：目录正常，第三方解析依赖失败

`resolveNiuguoMedia` 依次尝试主解析服务的 `qy.php`、`dj.php`，再尝试备用 IP 的同两条路径。独立探针未到媒体下载阶段：主解析主机 DNS 失败，备用服务连接后返回空响应，正常预算下最终仍失败。因此现有证据支持修复/替换经过验证的解析服务，而非单纯增加超时或更换作品 ID。

相关代码：[provider_duanju_sources.go](../native/core/internal/app/provider_duanju_sources.go) 的 `resolveNiuguoMedia`，以及 [provider_duanju.go](../native/core/internal/app/provider_duanju.go) 的解析线路常量。当前只显示最后一个错误，也值得补上安全的分阶段诊断，以免首个线路故障被覆盖。

### 超果：来源播放模式已经改变

当前五个详情页都有正常标题和集数按钮（5、36、21、32、43 个），但 `data-src` 均不存在，`#player-data` 只有选集信息。当前[前端脚本](https://www.shanekids.com/static/app.js) 在用户点击播放时向 `/api/play` 提交作品 ID、序号与 view 值；页面显示每集 10 币并处理余额/门槛响应。本轮没有调用这个扣费接口。

`chaoguoChapters` 仍要求按钮带有直接 `data-src`，所以返回“未解析到可播放分集”。这不是站点关停，但不符合当前无需账户/支付的直链适配方式。若继续支持目录，可明确浏览能力；把账户或扣费播放接入 App 应单独作为产品功能设计。相关代码：[provider_duanju_chaoguo.go](../native/core/internal/app/provider_duanju_chaoguo.go)。

### 黄果与爽果：按子线路或能力处理

黄果失效的是 `huangguo-video`，当前目录合并仍有旧黄果和 AI 的 368 条，两个分支的样本媒体都能取得。`mobileHuangguoCatalog` 的错误分支会保留游标以重试，坏子线路会继续参与后续页请求。应修复可达入口或暂时跳过这一个分支，并保留健康分支及部分结果反馈。相关代码：[mobile_huangguo_catalog.go](../native/core/internal/app/mobile_huangguo_catalog.go)。

爽果的联网搜索验证触发整域退避后，文字巡检中的详情/分集显示失败，但这两步 `networkAttempts=0`。干净会话的详情和媒体通过，表明不应将这些结果算作详情接口独立失效。不过手机目录失败是真实的设备反馈，不能被主机通过覆盖。因此将远程搜索降级为本地筛选，加入既有浏览器兼容连接，并在设备验收前默认停用。相关代码：[provider_duanju_maccms.go](../native/core/internal/app/provider_duanju_maccms.go) 和来源能力声明。
