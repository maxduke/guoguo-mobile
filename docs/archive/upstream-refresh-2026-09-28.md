## 范围

新增芽果（yaguo）、猫果（maoguo）、饭果（fanguo）、观果（guanguo）、河果（heguo）、星果（xingguo）、花果（huaguo）、牛果（niuguo）、网果（wangguo）、发果（faguo）、皮果（piguo）、伍果（wuguo）。通过现有移动端适配表接入分类、目录、搜索、详情、分集与播放解析；移动端分页优先使用接口明确返回的是否有下一页标记，缺失时再依据总页数或条目数量判断；芽果、饭果及发果的单页搜索不虚构下一页。

芽果令牌获取保留调用方取消信号，缓存按登录接口地址隔离，避免不同接口配置之间复用令牌。

河果搜索使用 `POST /seo/video/6007`，星果使用 `GET /novel-api/basedata/book/searchBook` 的 `key` 参数；猫果标题清理搜索高亮标签。沿用本项目的媒体代理、授权隔离和原生播放器，不覆盖已有剧果、野果、帝果集成。

Flutter 站源枚举增加十二项，仍按原有字符串 ID 保存身份；新站源复用分类缓存、在线搜索和离线恢复。列表横向滚动，收藏、历史、备份与下载沿用现有模型。

包内弹幕表情修改依赖弹幕功能；本项目尚未提供移动端弹幕接口或界面，本轮不新增该功能。未迁移上游桌面壳、多用户及播放器替换。
