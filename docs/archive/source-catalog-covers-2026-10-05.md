# 黄果封面、分页刷新与其它站源检查（2026-10-05）

## 参考与范围

参照 [maxduke/guoapp](https://github.com/maxduke/guoapp) commit
`5999e469e1281e55dcf603c980f83cd0ba00206d`，选择性迁移目录分页、封面 Referer、历史图片地址修复及 MacCMS 路径兼容思路。野果线路发现问题在参考版本中也存在，本轮按实际发布页修复。

保留移动端十六源、原有剧集 ID、收藏/历史/下载数据以及播放器和投屏实现；不整体替换上游核心，也不放宽 HTTPS、公网 DNS 与重定向安全限制。

## 修复

### 黄果刷新与加载更多

- “黄果”仍聚合旧接口、黄果 AI、黄果视频。原先移动端调用多分类、多排序的全量入口，并固定返回 `hasMore=false`；现在逐页调用旧接口 tab 列表、四个 AI 分类 API 和视频目录。
- 子源有限并发，各有 25 秒预算；部分失败保留已取得的结果并返回 warning，全失败明确报错。
- 三个子源分别保存下一页与结束状态，失败不推进该子源，其它子源可以继续；已经结束的子源不再反复请求。状态复用原子写入的 `library.json`，重启保留未补回的页。手动刷新重新扫描首页，不删除已缓存剧集。
- 手动请求不复用旧网页缓存；AI 响应必须有有效的目录结构，校验返回页码并读取分页信息，避免验证页或重复首页被当作成功。

### 封面

- 黄果图片不再发送过时的 `huangguoai.com` Referer；黄豆保留对应 CDN 的 `/home` Referer；其它源按真实来源设置请求头。
- 正确识别 `//host/path`，避免当成旧黄果的相对路径。只对旧黄果身份修复误挂在媒体 CDN 下的历史封面地址，不重写其它源的 CDN。
- 目录里的标准 HTTP 图片地址升级为 HTTPS 后再校验。星果实网返回 HTTP 封面，但对应 CDN 支持 HTTPS；旧代码直接把该字段丢弃。
- 保留失效封面按剧集身份重新获取、AES/XOR 解码和缓存隔离。读取通用源域名时补上互斥锁，避免跨源封面加载与线路更新并发读写 map。

### 其它源

- MacCMS 详情锚点新增 `/xzyxvd/<id>.html`，防止换模板后漏掉整张剧集卡片。
- 野果采用发布页当前内容域名 `.callawtj.cc`，兼容旧内容域名与 `.fzchosdi.cc` 备用线路，仍拒绝广告/未知域名。
- 发布页、明确选定的内容页及其 JS 模块不再被共享候选域名重新指向别的站点；保留自定义接口配置。修复前可复现“野果页面未提供有效的接口入口”，修复后已取得目录与封面。
