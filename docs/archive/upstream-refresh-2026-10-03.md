## 本轮保留与延期

- 保留本地 iOS AVPlayer／BetterPlayer、画中画、播放意图、下载授权、投屏与提前开播实验。
- 不替换所有持久化饭果／星果 ID；交换格式转换不等于全库身份迁移。
- 不引入桌面 mpv、Android SurfaceView、TV 焦点、多用户／登录、Emby、局域网同步、外部 xz 进程或弹幕。
- 不启用在线同系列补全、默认全库遍历、长时间全分类更新、任意 CDN 节点推测、在线新季通知或新的手势方案。
- 预览 token 与 reference Web UI 特有路径未扩张移动接口；本地没有对应新入口时不搬入死代码。亮屏和 iOS 生命周期继续沿用现有播放器规则。
- 不推测任意 CDN 的等价节点，也不整体搬入上游 goroutine recover；继续使用本地传输和显式错误边界。本轮没有重现需要新增 panic 兜底的移动异常。
- 观看历史已分离通知和异步编码；没有新增历史行编码缓存、无变化保存跳过或分类缓存独立落盘，后续依据设备写盘测量再细化。
- 本轮验证使用合成媒体、固定文本和本地 HTTP／TLS 服务；没有请求真实站源图片或视频。显示节流、异步编码的设备帧耗时、内存和耗电没有实测，不能据自动化测试承诺性能数值。
