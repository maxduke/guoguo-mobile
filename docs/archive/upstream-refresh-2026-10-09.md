## 本项目发现并修复的问题

- Flutter `discoveryColumn` 与移动 JSON 接口都没有携带手动刷新语义，Go `loadRankingPage` 始终收到 `false`；五分钟内点击刷新可能直接返回内存榜单。新增可选 `refresh`，下拉、更新按钮及首屏失败重试传到核心；普通读取和续页继续使用缓存。
- 移动接口丢弃 `fetchedAt` 和 `stale`，页面把旧结果写成当前时间。现在输出栏目身份、页码、原获取时间与回退标记，页面和持久缓存保留真实时间；回退页不继续混合续页。
- 黄果内容域名已轮换为官方入口发布的 `*.wrjmtnebd.cc`。本项目已有动态发现，不再硬编码新域名；榜单增加经过解析校验的线路尝试，全部失效后重新读取官方入口一次，总时限 18 秒，单线路最多 3 秒。自定义源配置保持隔离。
- 爽果的 HTTP 200 页面实际是滑动拼图“安全验证”。新增特定验证页识别并沿用请求退避，不能将它提交为空目录。
- MacCMS 详情保留本剧可识别分集，排除相关推荐及相同集号的重复线路；包装播放器最多继续读取两层，循环/未解析的 HTML 地址不交给播放器。
