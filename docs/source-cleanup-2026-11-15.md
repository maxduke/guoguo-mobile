## 野果接口发现

继续从选定内容线路的首页、入口模块和有界的一层导入读取公开配置，不执行 JavaScript，不固定轮换的模块文件名或公开密钥。旧的直接调用形式保持兼容；新形式必须同时关联已知野果规范接口函数、实际客户端 `baseURL` 调用、`window.location` 的来源变量及同一变量生成的 `/api.php`。

同来源地址只能来自已识别的野果内容站点。仍保留显式 API 配置优先、模块不得跨来源、发现总期限和取消约束；不会因任意脚本中的地址字符串切换接口。回归覆盖当前脚本形态、旧形态、未使用的地址函数、不匹配的来源变量和未知站点拒绝。

干净临时客户端实测取得 20 条目录、作品 `yeguo:3395` 的 10 集详情、首集媒体 HTTP 206，并完成该集媒体准备和 FFmpeg 全集解码。另一次独立巡检验证了 26 个分类、20 条目录、20 条排行、2 条搜索结果、详情与分集，以及 1024 字节媒体读取。未改动播放分集身份校验、响应解码及现有媒体代理。

## 默认入口与用户数据

米果、伍果、花果加入现有默认停用策略，普通选择面板默认隐藏，站源管理保留说明和恢复入口。默认策略不会写成用户主动隐藏；显式恢复仍通过 `enabledSources` 持久化，重启后生效。

保留所有来源 ID、适配器、收藏、观看记录、下载记录与缓存。旧偏好当前选中这些来源且未显式恢复时，启动回到红果；已保存的记录仍可查看。回归覆盖三源及既有爽果的启动回退、显式启用、收藏与观看进度保留，并调整站源管理回归以区分默认策略和主动隐藏。

主机通过的视频样本不能证明米果、伍果、花果在用户网络或设备上恢复；此次未将它们标记为已修复。野果同样尚待设备起播、切集及持续播放验收。

本地 Go 全量回归 828 项测试/子测试通过，8 项既有可选联网巡检未启用；野果相关竞态检查、`go vet ./...` 和格式检查通过。本机未安装 Flutter SDK，官方与镜像下载均返回 404，因此 Flutter 格式、分析和测试须以本次提交的 CI 结果为准，发布前仍须通过完整构建门禁。
