# 当前产品规格

2026-10-09，描述当前源码行为。iPhone / iPad 为当前交付重点；安装包按来源提交和构建记录核对，已发布版本可能早于当前源码。验证范围见 [实现状态](implementation-status.md)，工程职责见 [状态边界](app-state.md)。

## 导航与找剧

主导航为发现、追剧、下载，设置从页面入口进入。宽且有足够高度的可用窗口使用侧栏，其余窗口使用底部导航；切换窗口和标签保留当前页面、来源与位置。

发现首屏提供有限的真人剧、漫剧、AI 剧推荐或当前站源的热门栏目，保留搜索、完整剧库及完整榜单入口。推荐顺序、榜单排名和目录默认顺序各自使用实际接口结果，不互相替代。只加载当前需要的来源和栏目；有序缓存先展示，刷新失败保留现有内容。

剧库按当前来源浏览，支持实际分类、默认顺序、剧名、上线时间和热度排序。分类/排序在筛选中，失败重试原来源、分类和游标。独立搜索页提供最近词、联想、清空、提交与分页；输入法组合态结束后才提交。返回详情后保留搜索输入、结果和位置，退出搜索取消旧请求。

来源选择提供常用、最近和隐藏管理，全部来源始终可搜索。十六站按来源隔离资料、记录与缓存；十五站支持联网搜索，黄豆使用本地缓存筛选，黄果联网搜索仅对应 AI 子源。能力和健康反馈来自真实接口与最近请求，目录成功不代表所有分集都可播放。同名作品不跨站合并身份或进度。

## 追剧、详情与续播

追剧包含收藏、历史及最多三部最近可续播作品，记录筛选支持单站或全部。普通记录卡片也有明确的继续观看/下一集/重播及详情操作；等待更新和已看完保留状态与详情。历史管理为次级入口，删除历史不删除下载。

详情先呈现紧凑资料与分集，简介/标签展开阅读，同系列区域位于分集之后。分集范围、手动选择、定位当前及底部播放/下载操作保持一致；刷新失败保留已取得的资料和队列。

续播按分集 ID、真实集号与确认播完状态计算，队列位置不冒充集号。已确认播完且存在后续分集时进入下一集；连载最新集等待更新，明确完结且播完末集才显示已看完。离线按下载的原始位置判断相邻，缺集不会自动跨越；用户仍可主动选播后续已下载分集。

## 播放与投屏

保留选集、上下滑切集、倍速、清晰度、PiP、普通横滑预览进度和长按临时加速。进度条及明确的播放/暂停、相邻分集入口可直接操作；长按移动不再跳进度。取消触摸、切集、后台或失效菜单不会提交旧手势和操作。辅助导航启用时维持可达控件，读屏、触控目标和大字号由自动化及设备清单分别验证。

播放故障提供固定、可理解的提示和对应操作；自动网络恢复有预算，离线缺文件和已取消操作需要主动处理。实际准备资源、凭据、兼容回退和真实集号保持原有契约。

统一设备入口呈现 AirPlay、Google Cast 和 DLNA 的选择与状态，各协议使用独立实现。投屏时保持单一播放端；面板收起可继续控制，结束后按已确认的设备位置和暂停意图交回手机。AirPlay 使用独立原生队列，不能把其他协议或任意接收软件视为同样的连播/后台能力。跨页面投屏和其他协议队列属于待评估增量。

## 下载、离线与存储

默认展示全部下载，按剧收起分集，提供本地播放、继续观看/重播；展开后保留分集操作及滑动删除。来源、状态与排序集中到筛选，空间管理为次级模式。分集与整剧下载固定确认时选定的队列，不自动加入以后新增的分集。

原生任务可在系统允许的条件下后台传输；需要整理的媒体在前台整理成功后才作为完整离线视频。恢复签名地址只更新缺失任务，先验证资源结构、密钥/清单及完成分片身份，再改变旧任务。规划或恢复失败保留完成文件和可重试记录。

设置的存储入口显示下载、已保存临时媒体、播放缓存、封面及目录缓存的实际统计范围。读不到容量时显示未知，清理说明实际影响；保护正在播放/投屏/下载的资源以及收藏、历史、提醒和已读基准。目录磁盘缓存清理不等于删除当前页面已持有的内容。实际容量及尚无目录/分集硬容量限的边界见 [性能基线](performance-baseline.md)。

## 设置、备份与支持

设置分为外观、播放与网络、存储、记录备份、关于与支持。默认跟随系统主题及现有网络偏好；高级工具折叠，保留实验性提前开播和剧库 JSON/XZ 交换。播放诊断从问题反馈进入，记录结构化阶段，不包含资源地址、凭据或异常原文。

记录备份 v2 包含收藏、历史和新季提醒，不包含视频文件，也不是自动设备同步。导入先预览，确认后在记录事务内合并；写入失败不安装候选数据。高级剧库交换与用户记录备份是不同范围。

按全新安装维护：记录和偏好使用 `records.json`，可重建目录数据使用 `catalog-cache.json`；不增加旧安装迁移。旧文件不会被自动清扫，用户数据删除遵守明确的操作范围。

## 布局与验收

自动化覆盖小屏、大字号、长标题、暗色、短横屏、键盘、空/错误状态、操作标签和触控目标。窗口切换保留标签、来源、下载筛选，以及搜索输入/结果/位置；并发提示在受限区域内滚动，分享使用准备完成后的当前窗口锚点。

iOS 编译、模拟测试和主机性能样本不等于真机验收。剩余设备项、接收器兼容性、精确首帧、内存与能耗见 [设备清单](ios-device-checklist.md)。[性能报告](performance-baseline.md) 记录已测成本及保留存储、播放器、来源/交换功能和现有会话结构的依据；尚无数据支持的能力不预先扩建。
