# 果果 v0.20.13

- 增加红果播放资料的有界恢复：仅在内联模型缺少加密资料且身份、时长和实际尺寸可信时，最多读取一次官方备用模型；普通完整模型和缓存命中不增加请求。备用地址、画质、密钥或明文标记均须通过校验，未知加密和不可信地址不会进入播放候选。
- 红果注册失败或官方取源明确返回 403／429 时，停止本次批量后续取源并保留结构化诊断，避免继续尝试其他来源掩盖拒绝原因。已加入队列的下载继续运行；普通单集失败和其他站源仍按原流程处理。
- 站源诊断新增取源阶段、固定失败类型及有界响应读取量，便于判断取流失败发生在哪一步，同时继续隐藏完整地址、密钥、账号和响应正文。

真实主机探测验证了红果 58 集详情、媒体首段 HTTP 206 / 1024 字节及一集 CENC／MP4／FFmpeg 解码。受控传输验证了备用恢复和明确拒绝后的停止规则；该主机样本走的是完整内联模型，未证明真实备用接口触发。iOS、Android 手机与电视构建及来源包校验以本标签的发布工作流为准。实体 iPhone 上的备用恢复、切集、画中画和长时间连播仍待验收。

Android 手机与电视共用正式 APK，按 ARM32、ARM64 或 x86_64 架构下载一个即可，沿用项目固定签名。“果果 测试”使用不同应用 ID，数据分别保存。iOS 提供未签名 IPA，需自行签名安装。
