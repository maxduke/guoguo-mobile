# 果果 0.17.0

版本：`0.17.0+36`。

- 新增超果、米果、爽果，当前十九站；支持分类、在线搜索、详情、选集及现有播放/下载接口。米果分类目录按单页处理，搜索按实际分页加载。
- 修复发现页及榜单页手动刷新仍读取原生缓存的问题。黄果旧榜单线路失效时重新发现官方线路；刷新失败保留内容、原获取时间和缓存提示。
- 修正 MacCMS 导航混入目录、其他作品混入选集和重复集号；同步标题、详情链接及播放器包装页兼容。
- 源站返回安全验证页时明确报错并保留已取得内容。

十九源接入不等于十九源随时可用。本轮网络抽查中，黄果三榜各返回 20 项；超果目录、搜索、榜单及详情可解析；米果目录、搜索及可播样本的详情可解析，部分作品没有可播放分集。爽果偶尔返回浏览器验证页，复测目录可解析；皮果当前受浏览器验证限制，帝果在本网络连接失败。验证页会明确报错。

安装包和 CI 状态以当前提交对应的 Actions 为准。iPhone/iPad 的播放画面、连续播放、投屏与后台行为仍需真机复测；本轮不以主机解析和自动测试替代设备验收。IPA 需要自行签名侧载。

同步范围、取舍及验证见 [实施记录](../docs/archive/upstream-refresh-2026-10-09.md)。
