# 果果 v0.20.14

- 修复红果播放资料读取：优先使用当前官方播放接口和签名，仅在当前接口返回空正文时进行一次受限旧接口恢复；请求数量和总耗时有上限，并保留手机兼容的 AVC/HEVC 筛选。
- 修复黄果分集取源，改用当前分集播放接口，校验作品、集数和媒体地址，并按来源范围应用 CDN 播放请求头。
- 黄果主入口没有可用线路时，可从固定官方发布页读取候选线路并按既有身份规则验证；失败时保留已有线路。

主机协议检查验证了真实移动 API 的媒体读取和 FFmpeg 解码；这不代表 iPhone、Android 手机或电视设备上的起播、切集、画中画、后台恢复或长时间连播已验收。黄果官方入口在本机网络仍无法直接连接，自动发布页恢复由受控回归验证。实体设备和不同网络环境仍需单独验证。

Android 手机和电视共用正式 APK，按 ARM32、ARM64 或 x86_64 架构下载一个即可，沿用项目固定签名。“果果 测试”使用不同应用 ID，数据分别保存。iOS 提供未签名 IPA，需自行签名安装。
