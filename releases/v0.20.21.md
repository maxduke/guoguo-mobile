# 果果 v0.20.21

- 修复黄果播放中转返回 HTTP 503 时无法取流的问题。应用在同一条线路上尝试一次公开播放接口，并核对作品和集数。
- 恢复黄果原生分类请求。插件分集只交给对应的站源解析，避免与黄果等原生源的分集混用。
- 修复极速追剧的媒体跳转和 66 大片网的 HLS 分片读取。
- 插件选集跳过明确锁定的分集和没有公开分集的线路。站点未提供公开播放地址时，应用会给出具体提示。

在主机上，黄果 AI 漫剧、极速追剧、开心影院和 66 大片网均有样本经应用原生播放代理解码。片库抽到的作品仍无公开直连分集，开心影院仍有个别线路不可用。实际设备上的播放待复测。

Android 手机和电视按 ARM32、ARM64 或 x86_64 架构下载对应 APK。iOS 提供未签名 IPA，需自行签名安装。
