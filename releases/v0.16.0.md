# 果果 0.16.0

版本：`0.16.0+35`。本次完成移动端代码清理、状态拆分与页面更新优化。

## 安装前请注意

- **本版按全新安装维护，不保证从旧版本原地升级读取记录。** 如果需要继续使用旧版数据，请保留原安装及所需副本，不要直接卸载后期待自动恢复。
- 不再迁移旧 `state.json`，不再接受 v1 记录备份；记录备份统一为 v2。已有旧文件不会自动删除。
- 记录备份不包含下载视频；卸载应用可能同时清除本地记录和下载内容。
- 本页提供的是 **iOS 未签名 IPA**，需要使用自己的 Apple 账户和签名工具重新签名后侧载，不能直接点击安装。

## 本次优化

- 删除旧数据迁移和已下线站源的历史清理分支；保留记录与目录缓存隔离、原子写入、失败重试和损坏保护。
- 移除移动端不使用的桌面 Web 界面、命令行、桌面任务管理和 FFmpeg 安装器；保留当前站源解析、封面处理、媒体代理和移动端原生媒体处理。
- 设置、目录／搜索、个人记录拆成独立状态。观看进度和收藏在对应区域更新，不再触发应用外壳或播放器偏好的无关更新。
- 分离播放器进度／倍速控件及选集、相关剧集、更多操作弹层；保留现有播放、恢复、画中画与投屏会话机制。
- 整理 README 与历史更新说明，补充状态职责和局部更新回归测试。

## 相较上个公开版本 0.9.0

本包也包含此前开发版本的更新：

- 当前十六站目录、搜索与封面修复，包含黄果分页及野果接口修正。
- 红果同系列查询、新季提醒及记录与目录缓存分区保存。
- 有界首段预取、提前开播及播放恢复改进。
- 独立原生 AirPlay 队列、换集资源保留与重试，以及 Google Cast／DLNA 投屏和结束后的进度交接。

## 验证与限制

- 三批重构的 Flutter／Go 检查、iOS 构建及合并后的主分支 CI 均已通过；最终本地 Flutter 回归为 350 项通过、4 项环境限定测试跳过。
- 发布流程只使用本标签对应提交通过主分支 CI 后生成的 IPA，核对版本、构建号、源码提交及 SHA-256 后发布。
- CI 构建和自动测试不等于真机验收。AirPlay 接收器连播、画中画、后台下载及侧载权限仍需实际设备验证；Android 暂未完成验收。
- `SHA256SUMS` 用于校验安装包和 `build-info.json`；后者记录源码提交与构建地址。

更多说明见仓库中的 `CHANGELOG.md`、`docs/app-state.md` 和 `docs/implementation-status.md`。
