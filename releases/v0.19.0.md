# 果果 0.19.0

- 设置新增“站源诊断”，可查看和复制最近的目录、栏目、搜索及分集请求状态，区分缓存命中、联网尝试和失败类型。
- Wi-Fi 下剧库滚动停稳后可提前加载当前分类下一页，手动刷新、切换来源或分类、离开页面、进入后台时取消；失败不会跳页或替换已有内容。
- “剧库提前加载”独立开关默认开启，当前覆盖十六个分类源；红果、黄果和黄豆继续按需加载。
- 新增独立的十九源文本巡检，检查目录、栏目刷新、缓存、搜索、详情和分集，便于发现站点变动。
- 修复剧果分类数量增长后触发旧上限、无法加载分类的问题。

iOS 包未签名，需自行签名安装。站源诊断只保留本次运行最近 64 条，不含搜索词、剧集 ID、地址或异常原文。联网尝试不代表站点已收到请求，巡检结果不能代替实际播放验收。实现和验证范围见 [实施记录](../docs/source-diagnostics-prefetch.md)。
