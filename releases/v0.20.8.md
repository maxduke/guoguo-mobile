# 果果 v0.20.8

- 补充红果匿名播放身份的有限恢复：连续两轮官方接口请求全部返回空内容后，重新注册一次播放设备并继续取流。
- 同一失败期最多完成一次替代注册尝试。新身份仍无资源时停止重复注册；连接错误、业务错误和不兼容媒体不会触发这项身份恢复。
- 并发播放与预取共用进行中的注册，切集和退出可取消等待；更换身份后清理未来分集模型，旧请求不能重置新身份的恢复状态或重新填充旧缓存。
- 恢复耗尽时显示固定的稍后重试或切换网络提示，不显示设备标识、Cookie、媒体地址或底层异常正文。

这次适配参考 [hongguoTV issue #41](https://github.com/tsukiyo-zero/hongguoTV/issues/41) 和 [PR #42](https://github.com/tsukiyo-zero/hongguoTV/pull/42)。上游追加反馈与本轮真实探针均出现新注册身份仍返回空内容的情况，因此不能保证服务端异常窗口期间恢复播放，也不能据此判定所有用户或地区都发生相同故障。

本地 Go 全量、身份注册与旧响应竞态回归、Flutter 安全提示及静态检查的证据见[修复记录](https://github.com/maxduke/guoguo-mobile/blob/v0.20.8/docs/hongguo-identity-recovery-2026-11-02.md)。当前真实探针未取得播放模型，没有完成该次真实媒体解密或解码；模拟回归通过不等于 iPhone 已恢复可播。完整检查、双平台构建、包身份与校验和以本标签发布工作流为准。

Android 手机与电视共用正式 APK，按 ARM32、ARM64 或 x86_64 架构下载一个即可，沿用项目固定签名，可覆盖升级旧正式版。“果果 测试”使用不同应用 ID，数据分别保存。iOS 提供未签名 IPA，需自行签名安装；起播、切集、画中画与长时间连播仍需真机验收。
