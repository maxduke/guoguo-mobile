# 果果 0.13.0

构建号：29

- 投屏控制面板可收起和重新打开，电视继续播放，播放器保留控制入口。
- 从选择电视时的手机实际位置开始，并保留暂停状态；在线媒体和已完成的本地 MP4 均可投屏。
- 投屏期间暂停手机，阻止本地拖动、切集与 PiP，避免两端同时播放。
- 结束投屏前读取电视最终进度，确认停止后将位置和暂停／播放状态交回手机，保存到原分集记录。
- 状态读取失败保留已确认进度，电视未确认结束时保持手机暂停并允许重试；补齐连接取消、迟到结果和搜索面板快速重开的保护。
