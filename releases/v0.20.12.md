# 果果 v0.20.12

- 改进红果播放源识别，兼容视频模型顶层和嵌套的编码、加密及尺寸字段；优先按实际画面尺寸标记清晰度，保留仅提供清晰度标签的旧模型。
- 为每个清晰度保留有限数量的 AVC／HEVC 编码和备用地址。遇到主地址不可用时，现有播放器可先尝试同画质的其他兼容来源，再回退较低清晰度；重复地址会合并，ByteVC2 和缺少有效密钥或明确未加密标记的加密来源不会进入候选。

真实主机验证取得红果 58 集详情、媒体首段 HTTP 206 / 1024 字节，并完成一集 CENC／MP4／FFmpeg 解码。iOS、Android 手机与电视构建及来源包校验以本标签的发布工作流为准。主机解码不代替实体 iPhone 上的播放、同画质切源、画中画及长时间连播验收。

Android 手机与电视共用正式 APK，按 ARM32、ARM64 或 x86_64 架构下载一个即可，沿用项目固定签名。“果果 测试”使用不同应用 ID，数据分别保存。iOS 提供未签名 IPA，需自行签名安装。
