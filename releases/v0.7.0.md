# 果果 0.7.0

- 播放诊断新增“提前开播（实验）”，默认关闭；从头播放加密 MP4 可在首段准备完成后开始观看。
- 准备期间进度条标出已准备时长，后续内容继续处理；实验失败自动切回完整准备。
- 续播、画中画和投屏沿用完整视频；从后台返回时切回完整准备，保留进度、倍速和暂停状态。
- 实验任务限制临时空间和处理时间，切集、退出时取消任务并清理临时内容，不影响离线下载记录。
- 诊断可区分直接播放、完整准备、提前开播与兼容回退，不记录播放地址或密钥。

继续使用现有原生播放器和后台下载方式。实验结果来自合成媒体与自动化测试，尚需 iOS 真机确认首帧、耗电、画中画、AirPlay 和投屏；默认播放路径保持完整准备。
