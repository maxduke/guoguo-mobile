# 果果 v0.20.16

- 修复野果接口发现：支持网站当前的同来源接口地址生成方式，恢复目录、搜索、详情和播放；保留旧配置兼容、线路校验和取消约束。
- 按设备实测反馈默认停用米果、伍果、花果。站源管理仍可手动恢复，选择会保留到重启后。
- 保留这些来源的收藏、观看进度、下载记录和缓存；旧偏好选中停用来源且未手动恢复时，启动回到红果。

野果已通过主机干净会话的目录、分集、首集媒体准备及 FFmpeg 全集解码。米果、伍果、花果的主机样本虽能解码前 20 秒，但用户设备仍有失败反馈，本次未标记它们已修复。野果设备起播、切集及持续播放仍待实测。

Android 手机和电视共用正式 APK，按 ARM32、ARM64 或 x86_64 架构下载一个即可，沿用项目固定签名。“果果 测试”使用不同应用 ID，数据分别保存。iOS 提供未签名 IPA，需自行签名安装。
