# 果果 v0.20.0

- 新增 Android 手机与 Android TV／电视盒子 APK 构建、签名和安装包校验；覆盖 ARM 32 位、ARM 64 位和 x86_64。
- 电视设备自动启用侧栏导航、较大控件及焦点提示，支持遥控器方向／确认、播放暂停、快进退和切集按键。
- 修复观果详情与按集播放解析，验证作品和分集身份，播放时刷新媒体地址。
- 统一备份导入／导出大小限制，大备份编码与校验移到后台，避免生成自身无法导入的备份。
- 下载记录损坏时支持检查、导出原件和确认修复，保留无法识别的原有视频文件。
- 下载进度按任务增量更新，隐藏的追剧／下载页面暂停展示刷新及动画。
- 补充封面请求与图片解码诊断、原生请求退出取消，以及小样本媒体巡检。

APK 构建、包身份与遥控器界面测试不等于所有电视盒子的解码、后台下载和长时间播放验收。黄果保持现状；皮果、牛果、超果和爽果继续默认停用。
