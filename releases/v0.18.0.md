# 果果 0.18.0

- 红果搜索先展示名称检索与官网结果，可通过“加载更多”分批查找缺失季和后续季，首屏不再等待补季完成。
- 续搜按页面独立保存状态，切换搜索、取消和重试不会推进其他页面；空批次仍可继续查找已知缺失季。
- 同系列联网补全和新季检查继续遵守三页、二十秒预算，未完整的结果不建立提醒基准。
- 重启后保留搜索资料缓存，重新取得可用续搜状态；续搜过期时保留已显示结果，允许重新搜索。

iOS 包未签名，需自行签名安装。分季匹配依据剧名，不代表站源官方关联；实际结果以站源返回为准。范围与验证见 [分季续搜记录](../docs/hongguo-season-continuation.md)。
