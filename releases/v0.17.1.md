# 果果 0.17.1

版本：`0.17.1+37`。

包含 [0.17.0 的站源更新](v0.17.0.md)：新增超果、米果、爽果，当前十九站，并同步 MacCMS 目录、选集、标题及播放器包装页兼容修复。

- 修复黄果入口、榜单和分类请求遇到系统 DNS 保留地址时，在连接前直接失败、无法使用已有可信 DNS 回退的问题。回退结果仍须是公网地址，并保留原始 Host、TLS 名称及代理设置。
- 黄果榜单单条线路等待从 3 秒增至 8 秒，线路发现单次限制 8 秒，总体限制 30 秒，给 DNS 回退和 TLS 连接留出时间。
- 首页和全部栏目加载失败增加固定提示，区分域名解析异常、连接超时、浏览器验证及站点限制。原始 URL、凭据和 IP 地址不会进入提示。

自动测试复现了旧版在保留 DNS 地址下零连接、零站点请求的失败，修复后验证空缓存线路发现、榜单刷新及四类目录请求；也验证可信 DNS 返回内网地址时仍拒绝连接。界面测试确认首次失败后点击首页刷新和全部栏目“重试”会再次调用核心，并强制刷新榜单。慢连接测试复现并覆盖旧版 3 秒提前放弃的情况。

用户已在原有代理／自定义 DNS 的 Wi-Fi 环境完成真机复测，反馈本版本测试无问题。自动测试、真实站点请求及这次真机结果共同覆盖了本轮修复；其他网络环境若仍遇到失败，可依据新增提示继续定位。IPA 需要自行签名侧载。
