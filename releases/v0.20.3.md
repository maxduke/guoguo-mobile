# 果果 v0.20.3

- 修复 TV 播放时有声音但停留封面的问题：保留稳定的视频视图，准备完成后移除封面，电视使用旧版 OpenGL 兼容路径。
- 优化遥控器导航：首页导航与内容区独立，右键进入并恢复原位置；海报按行列移动，每张只有一个焦点，收藏在详情页操作。
- 改善详情和选集：默认聚焦观看按钮，上键定位续看集；“定位当前／跳集”下键进入分集，翻页自动交接焦点，返回恢复原项目。
- 放大带文字的播放与换集按钮，加强焦点边框；左右键限定在控件行，进度条支持上下键离焦，返回先收起控件再退出。选集和设置采用居中面板，媒体播放／暂停键读取实时状态。
- “更多播放设置 → 画面状态”区分源清晰度档位、视频尺寸、应用画布、电视输出和缩放方式，便于排查画质或显示问题。
- Android 按 ARM32、ARM64、x86_64 提供优化编译的独立 APK，减少安装空间；正式版沿用项目固定签名。

Android 手机与电视共用同一套 APK，按系统架构下载一包即可；正式应用名称为“果果”，可覆盖升级旧正式版。此前的“果果 测试”使用不同应用 ID，数据与正式版分开保存。iOS 提供未签名 IPA。

用户在原电视复测 0.20.3+57 后反馈基本正常，同意发布；这不能推断其他型号或长时间连播均已通过。红果实流抽查为真实 1920×1080，码率及显示缩放仍会影响观看体验。范围见 [遥控器导航说明](https://github.com/maxduke/guoguo-mobile/blob/v0.20.3/docs/tv-remote-navigation.md)及[画质核对](https://github.com/maxduke/guoguo-mobile/blob/v0.20.3/docs/tv-quality-2026-10-26.md)。
